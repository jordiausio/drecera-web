# drecera — web

Landing en català de drecera, l'app nativa de descàrrega i conversió multimèdia per a macOS.

Domini: https://drecera.neurona.cat

Web estàtica, sense dependències ni scripts de seguiment. `bash build.sh` prepara `dist/`. El desplegament es gestiona amb Sites i la identitat de `.openai/hosting.json`.

Les versions binàries experimentals s'ofereixen a Releases, amb checksum SHA-256 i els avisos de compatibilitat i notarització. El codi de l'app es manté al repositori privat `jordiausio/videsc`; aquest repositori conté el codi públic de la web.
